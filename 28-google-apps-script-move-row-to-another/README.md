# Google Apps Script: Move a Row to Another Sheet When Status Changes to Done

When a row's status changes to Done, the whole row moves itself to a Done sheet, formatting included. Covers checkboxes, routing to different sheets by status, a different spreadsheet, and a move log.

**Full tutorial:** https://flowscripthq.blogspot.com/2026/11/google-apps-script-move-row-to-another.html
