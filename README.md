## Using the Apps Script code

1. Open [script.google.com](https://script.google.com) and create a new project (or open the spreadsheet/document the tutorial names and choose Extensions → Apps Script).
2. Paste the folder's `Code.gs` into the editor.
3. Follow the tutorial link for the setup steps (triggers, permissions, and configuration values are covered there).

## Using the Power Automate expressions

Power Automate has no importable code files — each folder's `snippets.md` collects the exact expressions, filter queries, and settings from its tutorial so you can copy them into the right action.
